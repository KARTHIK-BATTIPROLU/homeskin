# IMPLEMENTATION GUIDELINES

1. Use these prompts with AI image generators (Midjourney, DALL-E 3, Imagen, etc.) to produce the photography assets.
2. If image generation is not available or assets are pending, use the SVG placeholders in `assets/images/` or placeholder files with the exact names.
3. Maintain consistent lighting, materials, and colour palette across all images.
4. Always apply `object-fit: cover` on gallery and responsive image containers.
5. Apply `loading="lazy"` for all non-hero images.
6. Use responsive `<picture>` tags with `hero-kitchen.webp` for desktop and `hero-mobile.webp` for mobile.
7. Never embed text directly into generated images; provide overlay text using HTML/CSS.
8. Add descriptive SEO-friendly `alt` text to every image.
9. Keep the protective film visually subtle and transparent.
10. Never claim that HOMSKIN is completely scratch-proof, heat-proof, or damage-proof.
11. Present HOMSKIN as a premium luxury interior-care brand rather than an industrial film manufacturer.
